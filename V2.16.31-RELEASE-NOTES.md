# V2.16.31 — Delivery Challan: snapshot + RTD generate

## Snapshot guarantee
- DC line amounts/descriptions are frozen at create time from Order or Invoice.
- Prefer Invoice taxableAmount when linked; else Order line amount / actualSaleAmount.
- Never re-reads Rate Master when printing or viewing old DCs.
- `buildDeliveryChallanCreateInput` / `createDeliveryChallanFromOrder` enforce this.

## UI
- Admin Order Detail (RTD):
  - When Tax Invoice already issued → **Generate Delivery Challan** (links invoice + snapshots values)
  - When no invoice yet → can still **Generate Delivery Challan only** (Job Work / other)
- Confirm step explains snapshot behaviour
